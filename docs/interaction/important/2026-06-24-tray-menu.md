# 系统托盘菜单

## 托盘图标

- 使用螃蟹像素图标（16×16 或 32×32 px 的 ICO 文件）
- 程序启动即驻留托盘
- 不显示在任务栏（`skipTaskbar: true`）

## 右键菜单结构

```
┌─────────────────────────┐
│ Claude Crab · [当前状态]   │  ← 灰色，不可点击，显示螃蟹当前状态
│ ─────────────────────── │
│ 打开状态文件位置            │  ← 打开 signal 文件所在目录
│ ─────────────────────── │
│ 退出                      │  ← 关闭螃蟹程序
└─────────────────────────┘
```

## 菜单行为

- **打开状态文件位置**：用系统文件管理器打开 `~/.claude/status-bridge/` 目录
- **退出**：关闭所有窗口，移除托盘图标，结束进程

## 气泡通知

- COMPLETE 状态进入时触发气泡
- 气泡内容："任务完成！"
- 从托盘图标弹出（系统通知）或从螃蟹头顶弹出（Canvas 渲染）
- 3 秒后自动消失
- 点击气泡 → 提前关闭
