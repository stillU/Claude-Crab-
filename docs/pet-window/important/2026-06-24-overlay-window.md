# 桌面窗口系统

螃蟹渲染在透明无边框的桌面覆盖窗口上。

## 窗口属性

| 属性 | 值 | 说明 |
|---|---|---|
| 边框 | `decorations: false` | 无标题栏 |
| 背景 | `transparent: true` | 只渲染螃蟹像素，其余完全透明 |
| 层级 | `alwaysOnTop: true` | 始终在所有窗口之上 |
| 任务栏 | `skipTaskbar: true` | 不在任务栏显示 |
| 初始大小 | 128×128 px | 容纳 64px 螃蟹 ×2 缩放 + 边距 |
| 初始位置 | 桌面右下角 | 偏移：距右 60px，距底 80px |

## 点击穿透策略

动态穿透：鼠标在螃蟹区域内 → 关闭穿透允许交互；鼠标在区域外 → 开启穿透。

- 通过 Tauri `Window::set_ignore_cursor_events` 切换
- 每 100ms 通过 `setInterval` 检查鼠标位置（仅在 IDLE 态频繁检测；WORKING/COMPLETE/ERROR 降低到 500ms）
- 边界检测：以螃蟹矩形区域（当前帧内容 bounding box）为准

## 移动边界

- 螃蟹走动范围限制在当前主显示器桌面区域
- 碰到屏幕边缘 → 反弹（反转水平速度）
- 被拖拽后不限制位置，用户可放到任意位置
- 放下后下一次随机走动从放下位置开始

## 启动行为

- 程序启动 → 窗口出现在桌面右下角
- 初始状态 IDLE
- 5 秒后开始检查状态文件（等待 Claude Code hook 就绪）
