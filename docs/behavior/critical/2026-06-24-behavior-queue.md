# 行为调度 — 动作队列与优先级

## 行为类型

| 类型 | 描述 | 可中断 |
|---|---|---|
| 主循环 (primary) | 当前状态的核心动画循环，持续播放 | 是 |
| 随机插入 (random) | 在主循环中随机触发的一次性动作 | 否（播放完毕） |
| 一次性覆盖 (override) | 外部信号触发的覆盖行为 | 是（最高优先级覆盖） |

## 优先级规则

1. **override** — 最高优先级。用户交互直接触发（拖拽、点击关闭错误）
2. **random** — 中等优先级。叠加在主循环之上，播放完毕后恢复主循环
3. **primary** — 基础层。当前状态的主循环动画

当高优先级动作激活时：
- 低优先级动作暂停（保留当前帧位置）
- 高优先级动作完成后，恢复低优先级动作（从暂停位置继续）

## 动作队列

每个状态维护一个动作队列：

```
IDLE:       [walk循环] → [随机发呆] → [walk循环] → ...
WORKING:    [coding循环] → [随机擦汗] → [coding循环] → ...
COMPLETE:   [phone循环] (持续到超时或被信号打断)
ERROR:      [panic循环 + cloud图层显示]
SLEEP:      [sleep循环]
```

随机动作触发间隔：
- 走动中插入发呆：每 10-20 秒
- WORKING 中插入擦汗：每 8-15 秒

## 状态切换时的队列处理

- 清空当前队列
- 加载新状态的 primary 动作
- 重置随机动作计时器
